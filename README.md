# さっつーのAIエージェント：決済・デリバリーシステム（プロトタイプ）

本リポジトリは、調査レポート販売サイト「さっつーのAIエージェント」における、特定商取引法に準拠した決済フローおよびデジタルコンテンツ（PDFレポート）の自動デリバリーシステムの動作確認用プロトタイプです。

## 概要
ユーザーがWordPress上のリンクから遷移し、注文内容の最終確認を経て、安全に商品をダウンロードできるまでの動線を実装しています。

## 実装されている主要機能
- **最終確認画面（/confirm）**: 経産省のガイドラインに基づき、購入確定前に「商品名」「価格」「返品規定」「引渡時期」を表示。
- **デリバリー機能（/success）**: 決済（シミュレーション）完了後、即時にPDFファイルをダウンロード可能。
- **特定商取引法ページへのリンク**: 運営者情報および規約へのアクセシビリティを確保。

## 技術スタック
- **Backend**: Python 3.10+ / Flask
- **Infrastructure**: Railway (Auto-deploy from GitHub)
- **Deployment URL**: https://(あなたのRailwayのURL).up.railway.app/confirm
